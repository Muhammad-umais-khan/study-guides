Functions of Two Variables (13.1)

Plain English. A function of two variables is a machine with two inputs and one output: z = f(x, y). Picture a vending machine: pick a row (x) and a column (y), get one snack (z). The domain is every (x, y) pair the machine accepts. The range is every output it can give. The graph is a surface floating over the xy-plane, and a level curve f(x, y) = c is a contour line on a hiking map: all points at the same height c.

How to Think & Spot It

√ (square root) → the inside must be ≥ 0.
ln → the inside must be > 0.
Fraction → the bottom must not be 0.
sin⁻¹ or cos⁻¹ → the inside must be between −1 and 1.
Range: ask "what values can the last operation produce?" The full method is in lesson 3 below.
Q5–8 trick: if z appears only to the first power you can solve for one z, so it is a function (Q5, Q8). If z² appears you get ±, two answers, so it is not (Q6, Q7).
Trap: in Q9–20 write every substitution in brackets, e.g. f(3, y) = 2(3) − y + 3.

Concepts, one at a time

1. What "f(x, y)" actually means

The letters in brackets are the inputs. f(2, 3) means "put x = 2 and y = 3 into the rule". Nothing else changes: you replace every x and every y, then do the arithmetic.

f(x, y) = x² + y → f(2, 3) = 2² + 3 = 4 + 3 = 7. And f(1, t) = 1² + t = 1 + t (a letter can be an input too).

2. Finding a domain: the 4-check recipe

The domain is "everything allowed". Scan the formula for the only four things that can go wrong: a square root (inside must be ≥ 0), a logarithm (inside must be > 0), a fraction (bottom must not be 0), and sin⁻¹ / cos⁻¹ (inside must be between −1 and 1). Write each as an inequality, then combine them.

f(x, y) = √(4 − x² − y²). Need 4 − x² − y² ≥ 0, i.e. x² + y² ≤ 4: a solid disk of radius 2. The inside runs from 0 to 4, so √ gives 0 to 2: range [0, 2].

3. Finding the range: the "last operation" method

The domain asks "what can go in?" The range asks "what can come out?" It is every output value the function really reaches. Do it in four steps:

  1. Find the domain first. Only allowed inputs count.
  2. Name the inside. Call the part inside the last operation u. For ln(xy − 6) the inside is u = xy − 6. For √(4 − x² − y²) it is u = 4 − x² − y².
  3. Ask what values u can take over the whole domain. Try the extremes: where is u biggest, where is it smallest, and can it hit everything in between?
  4. Push those u-values through the last operation. Use this cheat-sheet:
√unever negative. If u covers [a, b], the output is [√a, √b].
eualways positive, never 0. If u covers all numbers, the output is (0, ∞).
ln ucan be any real number if u covers (0, ∞).
sin⁻¹ uoutput is an angle in [−π/2, π/2].
cos⁻¹ uoutput is an angle in [0, π].
u²never negative, so the output is [0, ∞) if u covers all numbers.
Q27: f = √(4 − x² − y²). Domain: x² + y² ≤ 4. Inside u = 4 − x² − y². It is biggest at the origin (u = 4) and smallest on the circle (u = 0), and it takes every value between. So u covers [0, 4]. The square root of [0, 4] is [0, 2]. Range: [0, 2].
Q28: f = √(9 − 6x² + y²). Domain: 9 − 6x² + y² ≥ 0. Inside u = 9 − 6x² + y². Taking y large makes u as big as we like, and u = 0 is reachable (for example x = √1.5, y = 0). So u covers [0, ∞) and so does √u. Range: [0, ∞).
Q22: f = exy. Domain: all (x, y). Inside u = xy. With x = 1, u = y can be any number, so u covers all real numbers. eu of all real numbers is every positive number. Range: (0, ∞).
Q21: f = 3x² − y. Domain: all (x, y). For any target number k, choose x = 0 and y = −k to get f = k. So every number is hit. Range: all real numbers.
Q29: f = cos⁻¹(x + y). Domain: −1 ≤ x + y ≤ 1. Inside u = x + y covers all of [−1, 1] (for example x = u, y = 0). cos⁻¹ turns [−1, 1] into angles from π down to 0. Range: [0, π].
Q31: f = ln(5 − x − y). Domain: 5 − x − y > 0. The inside u = 5 − x − y can be any positive number (pick x = 5 − u, y = 0). ln of every positive number gives every real number. Range: all real numbers.

Two traps. (1) Do not just copy the outer function's usual range: if u is limited to [0, 4] then √u is limited to [0, 2], not [0, ∞). (2) A range must be proved reachable: always show one input that gives the extreme value (and, for "everything", a rule that produces any target value).

4. Level curves: slicing the surface

Set f(x, y) equal to a constant c. The points that satisfy it form a curve: every point on it has the same height c. A contour map is a stack of these curves. Lines packed close together mean a steep hill; lines far apart mean a gentle one.

z = x² + y², c = 4 → x² + y² = 4, a circle of radius 2. Bigger c gives bigger circles, so the surface is a bowl.

Partial Derivatives (13.3)

Plain English. A partial derivative asks: "if I nudge only x and freeze y, how fast does z change?" So for fx treat y as a plain number (like 7) and differentiate normally; for fy do the opposite. It is the slope of the surface in the x-direction (or y-direction). All the old rules (power, product, quotient, chain) still work. Second partials: fxy means differentiate by x first, then y; for nice functions fxy = fyx.

Algebra & Derivative Rescue

Exponential chain rule: d/dx(e−x) = −e−x: keep the exponential and multiply by the derivative of its inside, −1.
If eu = 0: set the exponential equal to zero; taking ln would require ln(0), which is undefined. Since eu is always positive, write no solution for that case.
Even roots need both signs: y2 = 1/2 gives y = ±√(1/2), not just the positive root.
Avoid a three-piece product rule: for zx = (−2x)(3/2 − x2 + y2)e1−x²−y², multiply the first two factors first: (−3x + 2x3 − 2xy2)e1−x²−y². Now the second partial uses the standard two-factor product rule.
Plug in early for second partials: keep zxx and zyy in their unsimplified product-rule form and substitute the critical point immediately. Zero factors then disappear before you do extra algebra.

How to Think & Spot It

Q5–10 (quotient rule or not?) Use it only if the variable you differentiate by is in the denominator. Q6, Q8, Q9 yes. Q5, Q7, Q10 no (the bottom is a constant, just pull it out).
Q39–40: ∂/∂x of ∫xy g dt = −g(x) (x is the lower limit, so a minus). ∂/∂y = g(y).
Q41–44: limit definition: fx = lim [f(x+Δx, y) − f(x, y)] ÷ Δx as Δx → 0. For √ multiply by the conjugate.

Trap: forgetting the inner chain-rule factor, e.g. ∂/∂x of tan(2x − y) has a 2.

Concepts, one at a time

1. Freeze one variable

To find fx, pretend y is a fixed number such as 7, then differentiate with respect to x like normal. To find fy, freeze x. Terms with only the frozen letter become constants and vanish.

f = x²y + 3y. For fx: y is 7, so x²·7 + 21 → 14x, which is 2xy. For fy: x² is a constant multiplier, so x²·y → x², and 3y → 3. fy = x² + 3.

2. Same thing, many names

fx, ∂f/∂x and ∂z/∂x all mean "partial derivative with respect to x". The curly ∂ just warns you there is more than one variable.

3. What the number means

fx(a, b) is the slope of the surface at (a, b) when you walk in the x-direction (y fixed). Positive means uphill, negative downhill. In word problems it is a rate: "output per extra unit of x" (e.g. °C per metre, dollars per stove).

4. Second and mixed partials

Differentiate twice: fxx (x then x), fyy, and the mixed ones fxy (x first, then y) and fyx. For smooth functions the two mixed ones are equal, which is a great way to check your work.

5. The limit definition

It is the slope formula "rise over run" with the run shrinking to zero: fx(x, y) = limΔx→0 f(x + Δx, y) − f(x, y)Δx. Plug in, simplify until Δx cancels, then let Δx → 0.

f = 3x + 2y: f(x + Δx, y) − f(x, y) = 3Δx, divide by Δx → 3. So fx = 3.

6. Rules that keep coming back

e and ln: (eu)′ = u′eu, so (e−x)′ = −e−x; (ln u)′ = u′ ÷ u. Differentiate the inside once. Split first: ln(a/b) = ln a − ln b and ln √u = ½ ln u remove the quotient rule. Signs: cos gets a minus, cosh does not. Product rule only when both factors contain your letter; a frozen factor just gets pulled out.

Common Point-Losers

Frozen letter: ∂/∂x(x²y) = 2xy, not 2xy + x². Do not differentiate the letter you froze.
Substitute last: plugging the point in first makes f a constant, so every derivative becomes 0.
Quotient rule test: look only at the denominator and ask whether it contains your letter.
fxy = fyx is a free check on your algebra.

Differentials (13.4)

Plain English. Δz is the true change in z when x and y change a little. The differential dz is a cheap estimate of it: dz = fx dx + fy dy, meaning "x-slope × x-nudge + y-slope × y-nudge". The smaller the nudges, the better the estimate.

How to Think & Spot It

Q3–8: just write dz = (zx) dx + (zy) dy (add (wz) dz for Q7–8).
Q9–14: (a) plug in both points and subtract for Δz; (b) dz uses slopes at the starting point, dx = 2.1 − 2, dy = 1.05 − 1.
Q15–18 (the big trick): the expression is "f(new point) − f(old point)". Spot f, the old point (x₀, y₀), then the answer is simply dz with dx, dy = new − old. Check: the subtracted part tells you the old point.

Concepts, one at a time

1. The big idea: zoom in and a curved surface looks flat

Near a point, a smooth surface is almost a flat tilted plane (the tangent plane). So a small step in x changes z by about (x-slope) × (step), and the same for y. Add the two effects.

2. Δz versus dz

Δz is the true change: new value minus old value. dz is the estimate from the slopes: dz = fx dx + fy dy, with the slopes taken at the old point. dx and dy are just the small steps (new − old).

A = lw, l goes 10 → 10.1, w goes 5 → 5.2. dA = w·dl + l·dw = 5(0.1) + 10(0.2) = 2.5. The true ΔA = 10.1·5.2 − 50 = 2.52. Very close.

3. Using dz to approximate a number

Steps: (1) decide which function f(x, y) the expression comes from; (2) pick a nearby "easy" point (x₀, y₀) where f is known; (3) dx = new x − x₀, dy = new y − y₀; (4) answer ≈ f(x₀, y₀) + dz.

Common Point-Losers

dz is not Δz. Δz is the true change, dz is the tangent-plane estimate.
Partials at the start point, not the new one.
Keep the sign of dx and dy: a drop from 6 to 5.95 is dy = −0.05.
Q15–18: the subtracted term tells you the old point.

Chain Rules (13.5)

Plain English. If w depends on x and y, and x and y depend on t, then t changes w along two roads. Draw a tree: w at the top, branches to x and y, each branch down to t. Multiply along each road, add the roads. Same idea for s and t. For equations like F(x, y) = 0 you get the shortcut dy/dx = −Fx/Fy.

How to Think & Spot It

dw/dt = wx·x′ + wy·y′ (one parameter).
∂w/∂s = wxxs + wyys (two parameters).
dy/dx = −Fx ÷ Fy (move everything to one side so it equals 0 first).
Shortcut: if w simplifies nicely (Q6: ln(y/x) = ln y − ln x), substitute first and check.
Trap: leave your answer in t at the end by replacing x, y; and do not forget the minus in −Fx/Fy.
Scope note: Q9–12, 19–22 and 27–34 involve three variables, so they are excluded.

Concepts, one at a time

1. Why two terms?

Suppose w depends on x and y, and both x and y depend on t. When t moves, x moves and y moves, and each pushes w. So there are two "roads" from w down to t, and you add their effects. Draw the tree: w at the top, branches to x and y, each branch down to t. Multiply along a road, add the roads.

dw/dt = (∂w/∂x)(dx/dt) + (∂w/∂y)(dy/dt)

2. Two parameters, s and t

If x and y depend on both s and t, w becomes a function of s and t, and you get two answers using partials: ∂w/∂s = wxxs + wyys, and ∂w/∂t = wxxt + wyyt. For ∂w/∂s, treat t as a constant everywhere.

3. Substitute first, or use the chain rule?

Both give the same answer. If w simplifies after substituting (like ln(y/x) = ln y − ln x), substituting is often quicker. If the substituted expression would be huge, use the chain rule and plug numbers in at the end.

4. Implicit differentiation shortcut

When y is tangled up in an equation (not solved for y), move everything to one side so it reads F(x, y) = 0. Then dy/dx = −Fx ÷ Fy. To get Fx, treat y as a constant; for Fy, treat x as a constant. Do not forget the minus sign.

Common Point-Losers

One term per branch. Draw the tree; a missing branch is the usual slip.
Never drop the minus in dy/dx = −Fx/Fy.
Leave the answer in t (or s, t) unless asked for a value.
Check by substituting first when w simplifies (Q6: ln(y/x) = ln y − ln x).

Directional Derivatives & Gradients (13.6)

Plain English. Standing on a hillside, the gradient ∇f = (fx, fy) is an arrow pointing straight uphill, and its length is how steep that is. The directional derivative Duf = ∇f · u is the slope if you walk in direction u. u must be a unit vector (length 1).

How to Think & Spot It

Recipe: 1) find ∇f, 2) plug in the point, 3) make the direction a unit vector, 4) dot product.
Direction clues: angle θ → u = (cos θ, sin θ).
Vector v → u = v ÷ |v| (3i − 4j has length 5).
Point Q → v = PQ = Q − P, then divide by its length.
"Maximum value" / "steepest" (Q29–38): the answer is |∇f|, in the direction of ∇f.
Trap: forgetting to normalise, and mixing up P and Q order. ∇f is perpendicular to the level curve.

Concepts, one at a time

1. The gradient is an arrow made of partials

∇f = (fx, fy). At each point it points in the direction where f climbs fastest, and its length is how steep that climb is.

f = x² + y² at (1, 2): fx = 2x = 2, fy = 2y = 4, so ∇f = (2, 4).

2. Directional derivative: slope in any direction

fx only measures the slope going east; the directional derivative Duf is the slope going in any direction u. Formula: Duf = ∇f · u (multiply matching components and add). If u = (cos θ, sin θ) this is fxcos θ + fysin θ.

3. Making a unit vector

u must have length 1, or the answer comes out too big. To fix any vector v: divide each component by its length |v| = √(v₁² + v₂²). If the direction is "toward Q", first build v = Q − P.

v = 3i − 4j, |v| = √(9 + 16) = 5, so u = (3/5, −4/5).

4. Max, min, zero

The largest possible slope is |∇f| (walk along ∇f). The smallest is −|∇f| (walk against it). The slope is 0 if you walk perpendicular to ∇f, which is along the level curve. So ∇f is always perpendicular to the level curve.

Common Point-Losers

Normalise: u must have length 1.
P to Q means Q − P, not P − Q.
"Maximum value" is the length |∇f|, a number, not the vector.
Plug the point in last, after taking partials of a product or quotient.
∇f points to the best local uphill direction, not necessarily to the global peak.

Extrema of Two Variables (13.8)

Plain English. Peaks (maximum), pits (minimum) and mountain passes (saddle) all have a flat tangent plane, so first find the critical points: fx = 0 and fy = 0 together. Then use the Second Partials Test with d = fxxfyy − (fxy)².

How to Think & Spot It

d > 0 and fxx > 0 → minimum.
d > 0 and fxx < 0 → maximum.
d < 0 → saddle.
d = 0 → test fails, so look at the function itself.
Q31–34: only second partials are given, so just compute d.
Hard-question cues: high powers (x⁵ + y⁵), fractional powers (Q20, partials undefined at the origin), or ex-style factors that can never be 0 (Q23: may give no critical points at all). Solve the system by substituting one equation into the other.

Algebra reminder: see the Algebra & Derivative Rescue in Section 13.3 for exponential-zero equations, the ± square-root rule, and a distribute-first shortcut for Q24.

Concepts, one at a time

1. Peaks, pits and passes

A relative maximum is the top of a hill, a relative minimum is the bottom of a bowl, and a saddle is a mountain pass: uphill in one direction, downhill in another. At all three, the surface is momentarily flat, so fx = 0 and fy = 0.

2. Step one: find critical points

Set fx = 0 and fy = 0 and solve both together. Solve one equation for a variable and substitute into the other (substitution), or add and subtract the equations (elimination). Also watch for points where a partial is undefined.

3. Step two: the Second Partials Test

At each critical point compute d = fxxfyy − (fxy)². If d > 0 the surface bends the same way in every direction: check fxx, and fxx > 0 means bowl (min), fxx < 0 means hill (max). If d < 0 it bends up in one direction and down in another: saddle. If d = 0 the test gives no answer.

4. When the test fails

Go back to the function. Ask: can f be negative or positive near the point? Is f always ≥ or ≤ its value there? Compare f along an axis. See Q16, Q20.

5. Two kinds of "point": (a, b) and (a, b, f(a, b))

The critical point is the 2D address (a, b) on the floor of the xy-plane. A saddle point is written as the full 3D point (a, b, f(a, b)). Relative extrema are described by the input (a, b) together with the value f(a, b). On an exam write both the location and the z-value, so you get credit whichever way the answer key words it. A critical point is still a critical point after you classify it as a saddle.

6. Plug the critical point in before you compute d

If the second partials still contain x or y (as in Q16: fxx = 20x³), evaluate each one at the critical point first: d = fxx(a, b) · fyy(a, b) − [fxy(a, b)]². For Q16 at (0, 0) every second partial is 0, so d = 0. If the second partials are plain numbers (Q9, Q17), there is nothing to plug in.

7. Never divide by a variable

After substituting (Q22: x = x⁹), move everything to one side and factor: x(x⁸ − 1) = 0. Dividing by x deletes the solution x = 0, and with it the critical point (0, 0). Also, an exponential such as e−x is never 0, so you may safely cancel it (Q23, Q24).

8. Exam write-up in four steps

  1. First partials, set both to 0, solve: list every critical point (and any point where a partial is undefined).
  2. Second partials fxx, fyy, fxy.
  3. At each critical point: evaluate them, compute d, read the verdict (d > 0 and fxx > 0 min; d > 0 and fxx < 0 max; d < 0 saddle; d = 0 look at f directly).
  4. Plug the point into f for the height, and write the final answer with location and value.

P3Domain with a root, a log and a line removed
mirrors 13.1 Q21–32

Describe the domain of f(x, y) = √y − x2ln(x + y).

Three conditions: (i) y − x2 ≥ 0: on or above the parabola y = x2; (ii) x + y > 0: strictly above the line y = −x; (iii) the denominator ln(x + y) ≠ 0 ⇒ x + y ≠ 1: remove the line y = 1 − x. The parabola and the line y = −x meet at (0, 0) and (−1, 1); between them (−1 < x < 0) the line is the higher curve, so that part of the boundary is the line (open) rather than the parabola. Domain: {(x, y): y ≥ x2, x + y > 0, x + y ≠ 1}. The origin is excluded.

P26Rates of change and units
mirrors 13.3 Q123–124

The temperature on a plate is T(x, y) = 100 − 2x2 − 3y2 − xy in °C, with x and y in metres. At (1, 2): (a) find Tx and Ty and say what each means; (b) in which direction does the temperature drop faster per metre? (c) If y is measured in centimetres instead, how is Ty written?

(a) Tx = −4x − y, Ty = −6y − x. Differentiate first, substitute last: Tx(1, 2) = −4 − 2 = −6 and Ty(1, 2) = −12 − 1 = −13. Meaning: moving 1 m in the +x direction lowers the temperature by about 6 °C; moving 1 m in the +y direction lowers it by about 13 °C. (b) The y-direction (|−13| > |−6|), since both rates are per metre. (c) −13 °C per metre = −0.13 °C per centimetre. The number changes with the unit, so compare rates only in the same units.
P27Total differential of a three-variable function
mirrors 13.4 Q7–8

w = x2 ey/z. (a) Find dw. (b) Use it to estimate the change in w when (x, y, z) moves from (1, 1, 1) to (1.02, 1.01, 0.99).

(a) wx = 2x ey/z. wy = x2 ey/z·1z = x2z ey/z. wz = x2 ey/z·(−yz2) = −x2yz2 ey/z (chain rule on the exponent). So dw = 2x ey/z dx + x2z ey/z dy − x2yz2 ey/z dz. (b) At (1, 1, 1) every exponential is e: wx = 2e, wy = e, wz = −e; dx = 0.02, dy = 0.01, dz = −0.01 (z went down). dw = 2e(0.02) + e(0.01) − e(−0.01) = e(0.04 + 0.01 + 0.01) = 0.06e ≈ 0.1631. (Exact change: 0.1675.)
P28Exact change versus the differential
mirrors 13.4 Q9–14

For f(x, y) = x2 ln y let (x, y) move from (2, 1) to (2.1, 1.05). Find (a) the exact change Δz, (b) dz, and (c) the error Δz − dz.

P29Estimate a logarithm with a differential
mirrors 13.4 Q15–18

Use dz to approximate ln[(1.02)2 + (0.97)2] given ln 2 ≈ 0.6931.

Take f(x, y) = ln(x2 + y2), base (1, 1), dx = 0.02, dy = −0.03. fx = 2xx2 + y2 = 1, fy = 1 at (1, 1). dz = 1(0.02) + 1(−0.03) = −0.01. So the value ≈ 0.6931 − 0.01 = 0.6831. (Exact: 0.6838.)
P31Two independent variables with a trig function
mirrors 13.5 two independent variables

w = sin(xy) with x = s + t and y = s − t. Find ∂w∂s and ∂w∂t, and evaluate both at (s, t) = (1, 1).

wx = y cos(xy) and wy = x cos(xy). Inside derivatives: xs = 1, ys = 1 and xt = 1, yt = −1 (the minus sign comes from s − t). ∂w∂s = y cos(xy)(1) + x cos(xy)(1) = (x + y) cos(xy) = 2s cos(s2 − t2) since x + y = 2s and xy = s2 − t2. ∂w∂t = y cos(xy)(1) + x cos(xy)(−1) = (y − x) cos(xy) = −2t cos(s2 − t2). At (1, 1): s2 − t2 = 0, cos 0 = 1, so ∂w∂s = 2 and ∂w∂t = −2. Check by substituting w = sin(s2 − t2) first ✓.
P32Implicit slope, two ways, and a tangent line
mirrors 13.5 implicit differentiation

For x2y + xy2 = 6 find dy/dx (a) with Fx and Fy, (b) by differentiating term by term, and (c) the tangent line at (1, 2).

On the curve: 1·2 + 1·4 = 6 ✓. (a) F = x2y + xy2 − 6, Fx = 2xy + y2, Fy = x2 + 2xy, so dy/dx = −2xy + y2x2 + 2xy. (b) Differentiate with y as a function of x (product rule on each term): 2xy + x2y′ + y2 + 2xy·y′ = 0 ⇒ y′(x2 + 2xy) = −(2xy + y2): the same ✓. (c) At (1, 2): Fx = 4 + 4 = 8, Fy = 1 + 4 = 5, slope −85. Tangent: y − 2 = −85(x − 1), i.e. y = −85x + 185.
